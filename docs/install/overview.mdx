OpSyn can be deployed using **Docker**, **Docker Compose**, and **Kubernetes**.

<Tip>
OpSyn is **free** and **open source**.
</Tip>

## Recommended Options

<CardGroup cols={2}>

  </Card>

  <Card title="Docker Compose" icon="layer-group" color="#00FFFF" href="./options/docker-compose">
