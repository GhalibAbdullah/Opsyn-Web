The Platform Admin is the central control panel for your OpSyn instance. From here, you manage projects, users, branding, security, billing, and infrastructure.

## Accessing Platform Admin

Navigate to `/platform` or click your organization name in the sidebar and select **Platform Admin**. The platform admin is accessible to all platform administrators.

### Setup

| Page | What It Does |
|------|-------------|
| [Branding](/admin-console/appearance) | Logo, favicon, primary color, platform name |

## Platform Plan & Feature Flags

Your platform plan determines which features are available. Each feature can be enabled or disabled:

| Feature Flag | Controls |
|-------------|----------|
| `analyticsEnabled` | Platform analytics dashboard |
| `tablesEnabled` | Built-in database tables |
| `todosEnabled` | Todo/task management |
| `mcpsEnabled` | MCP tool servers |
| `agentsEnabled` | AI agent capabilities |
| `environmentsEnabled` | Environment-based releases |
| `auditLogEnabled` | Audit log tracking |
| `embeddingEnabled` | Iframe embedding |
| `managePiecesEnabled` | Piece installation & management |
| `manageTemplatesEnabled` | Template management |
| `customAppearanceEnabled` | Branding customization |
| `manageProjectsEnabled` | Project management |
| `projectRolesEnabled` | Custom project roles |
| `customDomainsEnabled` | Custom domain configuration |
| `globalConnectionsEnabled` | Platform-wide connections |
| `customRolesEnabled` | Advanced role definitions |
| `apiKeysEnabled` | API key generation |
| `ssoEnabled` | Single Sign-On |

## Platform Notifications

The platform admin shows notification banners at the top of the Analytics page for important alerts:
- Subscription status warnings
- Feature upgrade suggestions
- System health alerts

These notifications are contextual and appear based on your platform's current state.

## Exiting Platform Admin

Click **Exit platform admin** at the bottom of the sidebar to return to your project dashboard.
