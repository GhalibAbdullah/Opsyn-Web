The Explore page is your template gallery — a curated collection of pre-built flows that you can use as starting points for your own automations.

## Accessing Explore

Navigate to **Explore** in the project sidebar (the first item at the top).

## Browsing Templates

### Search

Use the search bar at the top to find templates by name, description, or connected service. For example, searching "slack" shows all templates that involve Slack.

### Template Cards

Each template card shows:
- **Template name** — A short description of what the flow does
- **Pieces used** — Icons of the services involved (e.g., Gmail + Google Sheets)
- **Use Template** — Click to create a flow based on this template

## Using a Template

1. Find a template that matches your use case
2. Click on the template card to see details
3. Review the flow structure, description, and required connections
4. Click **Use Template** to create a new flow from it
5. You'll be taken to the flow builder with all steps pre-configured
6. Set up any required connections and customize the flow to your needs

<Tip>
  Templates are a great way to learn how flows work. Even if you don't use a template directly, exploring them shows you common patterns and best practices.
</Tip>

## Template Management (Platform Admin)

Platform admins can manage which templates appear in the Explore page:

- **Add templates** — Create custom templates in [Platform Admin → Templates](/admin-console/manage-templates)
- **Remove templates** — Delete templates that are no longer relevant
- **Template visibility** — All templates are visible to all project members

<Note>
  The Explore page shows templates configured by your platform admin. If the page is empty, ask your admin to add templates in the Platform Admin console.
</Note>

## Permissions

| Action | Who Can |
|--------|---------|
| **Browse templates** | All project members |
| **Use a template** | Users with flow creation permissions |
| **Manage templates** | Platform admins only |
