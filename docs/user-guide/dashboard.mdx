The Dashboard is your home screen when you first log in. It shows all your projects and provides quick access to platform settings.

## Accessing the Dashboard

The dashboard is accessible at `/dashboard` or by clicking **Home** in the top navigation.

## Onboarding Wizard

When you sign in for the first time, a **guided onboarding wizard** walks you through setting up your workspace:

### Wizard Steps

| Step | What Happens |
|------|-------------|
| **1. Welcome** | Choose between a guided setup or browsing templates |
| **2. Create Project** | Enter a name for your first project |
| **3. Create Flow** | Name your first automation flow |
| **4. Open Builder** | Go directly to the flow builder to start building |

### Options on the Welcome Screen

- **Start Guided Setup** — Step-by-step project and flow creation
- **Browse Templates Instead** — Jump to the template gallery and start from a pre-built flow

### Dismissing the Wizard

You can dismiss the wizard at any time:
- **Skip for now** — The wizard won't show again in this session, but will reappear next time
- **Don't show again** — Permanently dismisses the wizard

<Tip>
  The onboarding wizard only appears for new users who haven't completed or dismissed it before. If you've already set up a project and flow, you won't see it again.
</Tip>

## What You'll See

### Project Cards

The dashboard shows all projects you have access to as cards:
- **Project name** — Display name of the project
- **Created date** — When the project was created
- **Open Project** — Click to switch to the project and view its flows

### Quick Settings

At the top of the dashboard, you'll find shortcut cards:

| Shortcut | Destination |
|----------|-------------|
| **Platform Admin** | Full platform settings (admin only) |
| **Projects** | Manage all projects |
| **API Keys** | Manage API keys |

### Create New Project

Click the **New Project** button to create a project directly from the dashboard.

### Account Settings

Click **Account Settings** in the header to update your profile, change your password, or manage your account.

## Project Navigation

Once inside a project, the sidebar provides access to all features:

| Section | Description |
|---------|-------------|
| **Explore** | Browse templates and discover pre-built flows |
| **Flows** | Your automation workflows and run history |
| **Tables** | Built-in database tables |
| **Todos** | Task management and human-in-the-loop approvals |
| **Releases** | Environment & version management (Git sync) |
| **Integrations** | Browse and connect to 200+ services |
| **Connections** | Manage saved API credentials |
| **MCP** | AI tool server configuration |
| **Pieces** | Manage available integration pieces (under More) |
| **Environments** | Git sync and deployment environments (under More) |
| **AI Providers** | Configure AI model providers (under More) |
