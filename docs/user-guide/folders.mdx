Folders help you organize your flows into logical groups. Instead of scrolling through a flat list, you can categorize flows by team, function, client, or any structure that makes sense for your project.

## Where Folders Appear

Folders are visible in two places:

1. **Builder Sidebar** — The left navigation panel when editing flows shows flows grouped by folder
2. **Flows Dashboard** — The main flows list page can filter by folder

## Creating a Folder

1. In the builder sidebar, click the **folder icon** (➕) next to the "Flows" heading
2. Enter a folder name
3. Click **Create**

The new folder appears in the sidebar, sorted alphabetically among your other folders.

## Moving Flows to a Folder

When you create a new flow, you can choose which folder to place it in:

1. Click the **+** button inside a specific folder to create a flow directly in that folder
2. Or create a flow from the "Uncategorized" section and move it later

### Moving an Existing Flow

1. Open the flow's action menu (three dots)
2. Select **Move to Folder**
3. Choose the destination folder
4. The flow moves immediately

## The Uncategorized Folder

Flows that haven't been assigned to any folder appear in a special **Uncategorized** section at the top of the sidebar. This is the default location for new flows created without specifying a folder.

## Folder Actions

Right-click or click the menu icon on a folder to access:

| Action | Description |
|--------|-------------|
| **Rename** | Change the folder's display name |
| **Delete** | Remove the folder (flows inside move to Uncategorized) |

<Warning>
  Deleting a folder does **not** delete the flows inside it. They are moved to the Uncategorized section.
</Warning>

## Collapsing and Expanding

Click on a folder name to toggle it open or closed. The sidebar remembers which folders you have open:

- When you open a flow, its containing folder automatically expands
- Newly created flows automatically expand their target folder

## Permissions

| Permission | Who Can |
|------------|---------|
| **View Folders** | Anyone who can view flows |
| **Create/Rename/Delete Folders** | Users with `WRITE_FLOW` permission |
| **Move Flows Between Folders** | Users with `WRITE_FLOW` permission |
