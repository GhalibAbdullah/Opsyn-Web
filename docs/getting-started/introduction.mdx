## What is OpSyn?

OpSyn is an open-source workflow automation platform. It lets you connect 200+ apps and services, build powerful automations, and collaborate with your team — all with enterprise-grade security.

## Key Features

### Workflow Automation
- **Visual Flow Builder** — Drag-and-drop interface for building complex workflows
- **200+ Integrations** — Connect Google, Slack, GitHub, OpenAI, and many more
- **Flow Versioning** — Full version history with draft/publish lifecycle
- **Triggers & Actions** — Schedule, webhook, and event-driven automations

### AI-Powered
- **AI Workflow Generation** — Describe what you want in plain English and get a complete workflow
- **AI Agents** — Create AI agents that use tools to accomplish tasks
- **MCP (Model Context Protocol)** — Expose your tools to AI models like Claude and ChatGPT
- **AI Providers** — Configure OpenAI, Anthropic, Google AI, and more

### Team Collaboration
- **Real-Time Co-Editing** — Multiple people can edit flows simultaneously
- **Flow Comments** — Leave comments on workflows and individual steps
- **Activity Audit Trail** — Track every change made to a flow
- **Active Editors** — See who else is working on a flow

### Data Management
- **Tables** — Built-in spreadsheet-like database with typed columns
- **Table Automations** — Trigger flows when table data changes
- **Todos** — Task management with human-in-the-loop approval workflows

### Enterprise Ready
- **Projects** — Organize work into isolated projects
- **Platform Admin** — Manage branding, users, billing, and security
- **Role-Based Access Control** — Granular permissions with custom roles
- **Self-Hosted** — Deploy on your own infrastructure

### Developer Friendly
- **TypeScript Pieces** — Build custom integrations as npm packages
- **Hot Reloading** — Develop pieces locally with instant feedback
- **REST API** — Complete API for programmatic access
- **WebSocket Events** — Real-time event subscriptions

## Platform Architecture

OpSyn uses a multi-tenant architecture with two levels:

- **Platform** — Your organization. Controls branding, authentication, billing, and user management.
- **Projects** — Workspaces within your platform. Each project has its own flows, tables, connections, and team.

```
Platform (Organization)
├── Project A (Marketing Team)
│   ├── Flows, Tables, Todos, Connections
│   └── Team Members (with roles)
├── Project B (Engineering Team)
│   ├── Flows, Tables, Todos, Connections
│   └── Team Members (with roles)
└── Platform Admin
    ├── Branding & Appearance
    ├── User Management
    ├── Security (API Keys, Project Roles)
    └── Billing
```
